## About | 关于

CNPC Gecko Addon CE is a community-maintained continuation of the original CNPC Gecko Addon.

The goal of this project is not to replace the original addon, but to provide community-requested features, production-oriented improvements, and stability fixes while maintaining compatibility with existing CNPC content.

---

CNPC Gecko Addon CE 是原 CNPC Gecko Addon 的社区维护延续版本。

本项目并非为了替代官方版本，而是在保持兼容性的基础上。
根据社区反馈持续加入新功能、修复问题，并满足地图制作与脚本开发中的实际需求。

---

## Features | 功能

### Extended Animation System | 动画系统扩展

- Attack animation menu (up to 20 animations)
- Hurt animation menu (up to 20 animations)
- Death animation menu  (up to 20 animations)
- Weighted animation selection

- 新增攻击动画菜单（最多 20 个）
- 新增受伤动画菜单（最多 20 个）
- 新增死亡动画菜单（最多 20 个）
- 支持动画权重随机播放

### Script Model Controller | 脚本模型控制

Scripted items can now dynamically control Gecko models.

Supported operations include:

- Model
- Texture
- Animation
- Idle Animation
- Runtime animation playback
- Scale
- Rotation
- Display Size
- Display Offset

支持脚本载体动态控制 Gecko 模型。

包括：

- 模型
- 贴图
- 动画文件
- 待机动画
- 播放动画
- 缩放
- 旋转
- 物品显示大小
- 显示偏移

### Stability Improvements | 稳定性修复

- Fixed Gecko model jitter while NPCs are loading.
- Fixed limb flickering in heavily modded environments.

- 修复 NPC 加载 Gecko 模型时的抽搐问题。
- 修复多模组环境下上下肢部件闪回问题。

## Roadmap | 开发计划

This project currently prioritizes **Minecraft 1.20.1 Forge** and **1.12.2 Forge**.

Support for additional Minecraft versions may be considered in the future. If you would like to see support for another version, please open a **GitHub Issue**.

Planned features include support for **static OBJ models**.

---

## Roadmap | 开发计划

本项目当前优先维护 **Minecraft 1.20.1 Forge** 与 **1.12.2 Forge**。

如果你希望支持更多 Minecraft 版本，欢迎在 **GitHub Issues** 中提出需求。

未来计划支持 **OBJ 静态模型**（非骨骼动画）。
